# 🚀 EasyBot: 你的全能 AI 智能体桌面助手 (基于 Nanobot)

> **零代码 · 免 Python 环境 · 一键启动 · 多模型聚合 · 你的私人 AI 专家**

![EasyBot 截图](images/figures/图1.png)

## 📖 简介 | Introduction

**EasyBot** 是为普通用户量身打造的 **[Nanobot](https://github.com/HKUDS/nanobot)** 桌面封装版。它不仅仅是一个聊天工具，而是一个能帮你处理复杂任务的 **AI 智能体 (AI Agent)**。

我们深知，虽然现在的 AI 模型（如 DeepSeek、Kimi）非常强大，但繁琐的 Python 环境配置、API 密钥申请以及复杂的配置文件修改，将许多非技术用户拒之门外。

**EasyBot 的使命很简单：** 让最顶尖的 AI 触手可及。你**不需要写一行代码**，也不用懂什么是 Python，只需填入 API Key，就能瞬间拥有一个强大的本地智能助手。

---

## 💡 我能用它做什么？ | Use Cases

EasyBot 就像是一个住在你电脑里的全能专家，随时待命：

*   🎓 **学术科研**：帮你阅读几百页的论文 PDF，提取关键数据，甚至帮你润色英文摘要。
*   💻 **代码编写**：我是程序员的好帮手，能帮你写脚本、查 Bug、解释复杂的代码逻辑。
*   📝 **文案创作**：无论是写周报、写小说还是写小红书文案，我都能信手拈来。
*   🌍 **多语言翻译**：精准的英中互译，比机翻更懂语境。

## ✨ 核心亮点 | Features

### 1. ⚡️ 真正的“傻瓜式”运行 (Zero-Config)
*   **告别命令行**：不再需要输入黑框命令，也不需要安装Python 环境。
*   **独立运行**：全量封装为 `.exe` 软件，下载解压即用，简单得像打开 Word 一样。

### 2. 🧠 主流国产模型一站式集成
我们精选并适配了目前最强大的中文 AI 模型，你可以在软件界面中一键切换：

*   **DeepSeek (深度求索)**：目前最火的开源模型，逻辑推理与代码能力超强。
*   **Kimi (月之暗面)**：长文本处理专家，能一口气读完几十万字的小说或财报。
*   **Zhipu AI (智谱清言)**：全能型选手，综合能力均衡，指令遵循度高。
*   **Qwen (通义千问)**：阿里出品，知识储备丰富，不仅懂中文，更懂中国文化。

## 🚀 快速开始 | Quick Start

1.  下载本仓库中的 **`EasyBot.zip`** 压缩包。
2.  解压文件到任意位置。
3.  双击运行 **`EasyBot.exe`**。
4.  在弹出的界面中选择你想使用的模型（例如 **DeepSeek**）。
5.  **填入 API Key**（如果没有，软件会贴心地告诉你去哪里免费申请）。
6.  点击 **“启动助手”**，开始你的 AI 之旅！
