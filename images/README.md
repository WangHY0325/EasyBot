\# 🚀 EasyBot: 让 AI 触手可及 (基于 Nanobot)



> \*\*无需 Python 环境 · 零代码基础 · 一键启动 · 多模型聚合\*\*



!\[EasyBot 截图](images/figures/图1.png)



\## 📖 简介 | Introduction



\*\*EasyBot\*\* 是为普通用户量身打造的 \*\*\[Nanobot](https://github.com/HKUDS/nanobot)\*\* 桌面封装版。



我们深知，虽然现在的 AI 模型（如 DeepSeek、通义千问）非常强大，但繁琐的 Python 环境配置、API 密钥申请以及复杂的配置文件修改，将许多非技术用户拒之门外。



\*\*EasyBot 的使命很简单：\*\* 解放你的双手，让你\*\*不需要写一行代码\*\*，下载即用，瞬间拥有一个强大的本地 AI 助手。



---



\## ✨ 核心亮点 | Features



\### 1. ⚡️ 真正的“傻瓜式”运行 (Zero-Config)

\*   \*\*告别命令行\*\*：不再需要输入 `python main.py`，不再需要安装 Conda。

\*   \*\*独立运行\*\*：这是全量封装的 `.exe` 软件，无论你的电脑是否有 Python 环境，双击即可运行。



\### 2. 🧠 主流模型一站式集成

我们精选并适配了目前最强大的中文 AI 模型，你可以在软件界面中一键切换：

\*   \*\*DeepSeek (深度求索)\*\*：目前最火的开源模型，推理能力超强。

\*   \*\*Zhipu AI (智谱清言)\*\*：国产大模型代表，综合能力均衡。

\*   \*\*Qwen (通义千问)\*\*：阿里出品，长文本与逻辑分析能力出色。



---



\## 🚀 快速开始 | Quick Start



1\.  下载本仓库中的 \*\*`EasyBot.zip`\*\* 压缩包。

2\.  解压文件到任意位置。

3\.  双击运行 \*\*`EasyBot.exe`\*\*。

4\.  在弹出的界面中选择你想使用的模型（例如 DeepSeek）。

5\.  点击 \*\*“启动助手”\*\*，开始畅聊！
