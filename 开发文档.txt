# EasyBot V0.3 开发文档

**版本**: V0.3 (集成离线语音版)
**核心功能**: 本地化 AI 助手 GUI，支持多模型 API 切换，集成 Vosk 离线语音识别。

---

## 1. 环境搭建 (Environment Setup)

### 1.1 基础要求
*   **操作系统**: Windows 10/11
*   **Python 版本**: 建议 Python 3.10 或 3.11
*   **开发工具**: PyCharm 或 VS Code

### 1.2 初始化虚拟环境
为了保持环境纯净，建议在项目根目录下创建虚拟环境：

```powershell
# 1. 创建虚拟环境
python -m venv venv

# 2. 激活虚拟环境
.\venv\Scripts\activate
```

### 1.3 安装依赖
请确保项目根目录下有 `requirements.txt`，内容如下：

```text
PySide6
vosk
sounddevice
numpy
markdown
# 以下为 nanobot 核心依赖 (根据实际情况调整)
litellm
openai
rich
```

**安装命令**：
```powershell
pip install -r requirements.txt
```

## 3. 语音功能配置 (Voice Setup)

本项目使用 **Vosk** 进行离线语音识别，无需联网，不占用 GPU 显存。

1.  **模型下载**：
    *   模型名称：`vosk-model-small-cn-0.22` (约 40MB)
    *   下载地址：请访问 Vosk 官网或 GitHub 下载。
2.  **放置位置**：
    *   解压后，将文件夹放入项目根目录下的 `model` 文件夹中。
    *   确保路径存在：`V0.3/model/vosk-model-small-cn-0.22/conf/model.conf`

## 4. 打包发布 (Build / Packaging)

我们要将程序打包为 `.exe`，以便在没有 Python 的电脑上运行。为了保持安装包小巧（<100MB），我们**不将模型文件打包进 exe 内部**，而是采用“外挂”方式。

### 4.1 执行打包命令
请在终端（确保已激活虚拟环境）执行以下命令：

```powershell
pyinstaller --noconsole --clean -y --name "EasyBot" --icon="icon.ico" --add-data="icon.ico;." --add-data="skills;skills" --hidden-import="nanobot" --hidden-import="tiktoken_ext.openai_public" --hidden-import="litellm.litellm_core_utils.tokenizers" --hidden-import="vosk" --hidden-import="sounddevice" --collect-all "nanobot" --collect-all "rich" --collect-all "tiktoken_ext" --collect-all "vosk" --collect-data "certifi" --collect-data "litellm" --copy-metadata "pydantic" --copy-metadata "litellm" launcher.py
```

### 4.2 打包后处理 (关键步骤！)
打包完成后，`dist/EasyBot` 文件夹里会有 `EasyBot.exe`，但此时运行会报错“找不到模型”。

**必须手动操作：**
1.  找到您源码目录下的 `model` 文件夹。
2.  将其**复制**到 `dist/EasyBot/` 目录下。
3.  最终目录结构应为：
    *   `dist/EasyBot/EasyBot.exe`
    *   `dist/EasyBot/model/`

此时双击 exe 即可正常运行。

## 5. Git 版本控制 (上传至 GitHub)

由于您的项目总大小（包含代码和资源）小于 100MB，我们可以使用最简单的 Git 流程。

**仓库地址**: `https://github.com/WangHY0325/EasyBot.git`
*(注：如果仓库地址变更，请在下方命令中替换)*

### 5.1 首次上传 / 强制覆盖上传
如果您想把当前文件夹的所有内容推送到 GitHub，并覆盖之前的记录：

1.  **清理旧 Git 信息** (可选，防止冲突)：
    ```powershell
    Remove-Item -Recurse -Force .git
    ```

2.  **初始化并提交**：
    ```powershell
    # 初始化
    git init
    git branch -M main

    # 关联远程仓库
    git remote add origin https://github.com/WangHY0325/EasyBot.git

    # 添加所有文件
    git add .

    # 提交到本地
    git commit -m "Update V0.3: Voice Chat Integrated"
    ```

3.  **推送到 GitHub**：
    ```powershell
    # 强制推送 (慎用，会覆盖远程仓库的历史)
    git push -f origin main
    ```

### 5.2 日常更新 (非首次)
后续如果您只修改了代码（比如 `launcher.py`），使用以下标准流程：

```powershell
git add .
git commit -m "修复了xxx bug"
git push origin main
```

## 6. 常见问题排查 (Troubleshooting)

### Q1: 运行或打包后报错 `UnicodeEncodeError: 'gbk' codec...`
*   **原因**: Windows 终端不支持 ✅ 🔥 等 Emoji 字符。
*   **解决**: 确保 `launcher.py` 头部已加入以下代码：
    ```python
    if sys.stdout and hasattr(sys.stdout, 'reconfigure'):
        sys.stdout.reconfigure(encoding='utf-8')
    ```

### Q2: 语音识别报错 `Failed to create a model`
*   **原因**: 程序没找到模型文件夹。
*   **解决**: 检查 `model` 文件夹是否在 exe 同级目录下，且文件夹内部结构没有多余的嵌套。

### Q3: 机器人回复很慢
*   **原因**: 如果使用的是 DeepSeek 等热门 API，属于服务器侧延迟；或者是 Python 输出缓冲导致。
*   **解决**: 代码已内置 `PYTHONUNBUFFERED=1` 优化。如果是 API 问题，尝试更换模型测试。
